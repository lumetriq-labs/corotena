# モード別の統計（2026-11-05）

1日12試合（1試合約20分 × 約4時間）を想定し、メンバーを途中で変えずに1試合目から進めた場合のシミュレーション結果です。
`generateRound` を乱数のシード違いで繰り返し実行して集計しました。

- 休: 休み連続なし（`rest`）
- バ: バランス（`balance`）
- ペ: ペアかぶりなし（`variety`）

## 3試合続けて休む人が出た日の割合

1面・12試合 × シード100通り。

| 7人 | 0/100 | 1/100 |
| 8人 | 0/100 | 0/100 |

| 10人 | 0/100 | 93/100 |
| 11人 | 55/100 | 100/100 |
| 12人 | 100/100 | 100/100 |

バランスの11人1面では、出るのは9・10・12試合目で、ほとんどの日は1人だけでした。休み連続なしは、どの人数でも0/100です。

## 読み取れること

- 休みとペアの都合がぶつからない人数（5〜6人1面、2面のほとんど）では、3モードの結果はほぼ同じ。
- 8人1面の休み連続なしは、4人ずつの2グループが交互に出るだけになり、同じペアが繰り返される（12試合でかぶり12回、28ペア中12種類しかできない）。
- バランスは、7〜12人1面でかぶりと連続休みの両方が2つのモードの間に入る。
- 9人以上の1面では休む人が多いため、2連休の延べ回数はどのモードも同じ。違いはペアのかぶりと最長連続休みに出る。

## バランスの決め方

1. 出場回数をそろえる（差は1試合まで）
2. 「連続の休みの回数 + 選ぶペアが過去に組んだ回数」の合計が最小の組み合わせを選ぶ
3. 同点なら対戦相手のかぶりが少ないもの

## 採用しなかった案

- 重み付け（2連休3点、ペアのかぶりは回数の2乗、新しいペアに加点）: 8人1面で最初の混ぜ替えが13試合目まで起きず、1日の範囲では休み連続なしと同じだった。どの試合で混ぜるかが重みの組み合わせから間接的に決まり、予測しにくい。
- 連続休みに上限（11人以下2回、12人以上3回）をつけ、その範囲でペアを優先: 8人1面ではペアかぶりなしと同じ、10〜11人1面では休み連続なしと同じになり、中間にならない。
- 合計ルールに「3試合続けて休ませない」を追加: 11〜12人1面で休み連続なしと同じになる。
